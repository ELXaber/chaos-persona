1. Turn Structure

Both sides secretly choose an action (Move or Switch).
Reveal actions simultaneously.
Priority order:
Switching happens first (before any moves).
Then moves by Priority (higher first). Default Priority = 0.
Same Priority → higher Speed goes first. Tie → coin flip / alternate.

Resolve the faster action, then the slower one.
End of turn: status damage (Burn = 1/16 max HP, Poison = 1/8 max HP, etc.).
If a Pokémon’s HP reaches 0, it faints. Owner must switch in a new one (or loses if none left).
First side to have all Pokémon fainted loses.

2. Actions

Move X: Use one of the 4 moves on the active Pokémon.
Switch to Slot Y: Bring in another non-fainted Pokémon from the team (slots 1-3).

3. Stats
Each Pokémon has:

HP (current / max)
Attack (Atk)
Defense (Def)
Special Attack (SpA)
Special Defense (SpD)
Speed (Spe)

We use simplified “battle-ready” stats (already calculated for Level 50 with decent investment). No EVs/IVs/natures to track.
4. Damage Formula (simplified Gen 5+ style)
textBase = floor( ( (2 × Level / 5 + 2) × Power × (Atk or SpA) / (Def or SpD) ) / 50 ) + 2

Final Damage = floor( Base × STAB × TypeEffectiveness × Crit × Random )

STAB = 1.5 if move type matches one of the user’s types, else 1.0
TypeEffectiveness = 0, 0.25, 0.5, 1, 2, or 4 (from type chart)
Crit = 1.5 if critical, else 1.0
Random = 0.85 to 1.00 (we can agree on 0.925 average, or roll openly)

Physical moves use Atk/Def.
Special moves use SpA/SpD.
Status moves deal 0 damage and apply effects.
Minimum damage is 1 if TypeEffectiveness > 0.

6. Status Conditions (simple)

Burn: Physical attacks deal half damage. Loses 1/16 max HP each end of turn.
Poison: Loses 1/8 max HP each end of turn.
Paralysis: Speed becomes 50%. 25% chance to be fully paralyzed (skip turn).
Sleep: Cannot move for 1–3 turns (we decide duration when inflicted).
Freeze: Cannot move. 20% chance to thaw each turn.

Only one major status at a time.

9. How We Play

Decide who is Side A / Side B and which team each gets (or randomize).
Start with both sides sending out their first Pokémon.
Each turn: both of us post our chosen action in the agreed format.
One of us (or you) calculates the results using the formula above and posts the updated state.
Continue until one side has no Pokémon left.
